# Jan Christopher Buen — Portfolio

My personal portfolio site: who I am, what I've built, and the certifications I've earned.

Built by hand with plain HTML, CSS, and a little JavaScript. No framework, no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx http-server . -p 8080
```

## Files

- `index.html`: page content
- `style.css`: dark theme, layout, and responsive styles
- `script.js`: mobile menu toggle and footer year
- `Jan_Christopher_Buen_Resume.pdf`: downloadable resume
